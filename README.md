# نظام إدارة الخطة التشغيلية — بلدية النصيرات (Laravel)

تطبيق ويب متكامل ومؤمّن مبني بإطار العمل **Laravel (PHP 8.3)** لإدارة الخطط التشغيلية السنوية لبلدية النصيرات ومتابعة تنفيذها وتقييم أداء الدوائر.

## التشغيل السريع على Windows
يمكنك النقر المزدوج على ملف [`start_server.bat`](./start_server.bat)، أو تشغيل الأمر:
```bash
php artisan serve --host=127.0.0.1 --port=8000
```
ثم فتح الرابط: `http://127.0.0.1:8000`

## بيانات الدخول الافتراضية
- **المشرف العام:** `admin` / `Admin@1234`
- **حسابات الدوائر (تُطلب منها تغيير كلمة المرور عند أول دخول):**
  - الدائرة القانونية: `legal` / `Dept@1234`
  - الشؤون الإدارية: `admin_dept` / `Dept@1234`
  - الهندسة والمشاريع: `engineering` / `Dept@1234`
  - الدائرة المالية: `finance` / `Dept@1234`
  - الصحة والبيئة: `health` / `Dept@1234`

## أبرز المميزات المنفّذة
- **إدارة الدوائر والمستخدمين** مع إنشاء اسم مستخدم وكلمة مرور لكل دائرة وإلزام تغيير كلمة المرور عند الدخول الأول.
- **الهيكل الاستراتيجي الهرمي:** الأهداف الرئيسية ← الأهداف الفرعية ← البرامج (مع اختيار متسلسل تلقائي للدوائر).
- **بطاقة النشاط الكاملة:** النشاط، مؤشر الأداء، قيمة المؤشر، وسائل التحقق، الجهة المسئولة، الجهة المساندة (داخلي / خارجي)، الأرباع (ر1–ر4)، الأهمية، التكلفة، والترقيم التلقائي.
- **لوحة تحكم متقدمة** وإحصائيات ورسوم بيانية تفاعلية (Chart.js محلي يعمل دون إنترنت).
- **الاعتماد والرفض الفردي مع بيان السبب** + **الاعتماد والرفض الجماعي دفعة واحدة**.
- **التصدير إلى Excel وفق النموذج الأصلي** (مع شعار بلدية النصيرات) و**التقارير إلى Excel وPDF** بدعم كامل للغة العربية RTL عبر `PhpSpreadsheet` و`mPDF`.
- **المتابعة الشهرية المتقدمة** (12 شهراً) و**تقييم أداء الدوائر** و**إدارة التكاليف والموازنات** و**إدارة المخاطر والمعوقات (مصفوفة 5×5)**.
- **رفع المرفقات وأدلة الإنجاز** و**الإشعارات والمراسلات والتعليقات الداخلية**.
- **فتح وإغلاق فترات الإدخال** و**إدارة السنوات ونسخ الخطط السابقة**.
- **سجل التعديلات ومقارنة الإصدارات** + **سلة المحذوفات والاستعادة** + **النسخ الاحتياطي والاستعادة (ZIP)**.
- **الأمان وتجهيز النشر عبر الإنترنت:** راجع ملف [`DEPLOY.md`](./DEPLOY.md).
